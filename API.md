# API WAMM.chat

Карта методов для разработчика. Параметры, примеры и тела вебхуков — в справочнике, он главнее этого файла:

[https://wamm.chat/help/opisanie-api](https://wamm.chat/help/opisanie-api)

О сервисе: [README.md](README.md). Кабинет: [FEATURES.md](FEATURES.md).

## Зачем

Своя CRM, сайт или 1С отправляет сообщение с аккаунта компании и забирает ответ клиента, статус доставки и карточку чата. Отдельный API на каждый мессенджер собирать не нужно: адрес один, токен у канала свой.

В справочнике API названы такие каналы:

- WhatsApp
- личный аккаунт MAX
- личный аккаунт Telegram
- Telegram-бот

Один магазин может подтвердить заказ в WhatsApp, напомнить о доставке в Telegram и написать в MAX. Токен и вебхук у каждого канала свои.

## Адрес и формат

```text
https://wamm.chat/api2/
```

Ответ API и вызов на ваш Webhook URL приходят в JSON.

Успешная отправка:

```json
{"err":0,"msg_id":1000000}
```

Токен стоит в адресе запроса. Это секрет: не коммитьте его и не присылайте в переписке.

```text
https://wamm.chat/api2/msg_to/ВАШ_ТОКЕН/?phone=79001234567&text=Текст сообщения
```

Токен выпускается в кабинете: **Настройки → Управление → API**. Там же указывается адрес вашего сервера. На него WAMM.chat сам присылает входящие сообщения и статусы, опрашивать API для этого не нужно.

Токен не подошёл:

```json
{"err":"token fail"}
```

Канал ещё не авторизован, отправлять нельзя:

```json
{"err":"acc not authorized"}
```

## Группы методов

Названия как в оглавлении справочника. Вызов и поля — по ссылке на метод в базе знаний.

**Отправка**

- текст
- файл по публичной ссылке
- файл в BASE64
- правка уже отправленного сообщения

**Каналы и сотрудники**

- список каналов
- статус канала
- список пользователей кабинета
- проверка, есть ли номер в мессенджере

**Сообщения и статусы**

- входящие и статусы на Webhook URL
- список сообщений
- сообщения одного номера
- статус одного сообщения

**Чаты**

- открытые чаты сотрудника
- завершённые чаты

**Рассылки**

- список рассылок
- карточка одной рассылки

**Контакты**

- карточка контакта
- добавить или обновить
- удалить
- назначить ответственного
- открыть чат или завершить его

**Теги**

- список тегов чата
- добавить тег
- удалить тег

Нужного метода нет — напишите на [mail@wamm.chat](mailto:mail@wamm.chat). В справочнике указано, что методы добавляют по запросу.
